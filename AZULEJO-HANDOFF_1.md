# Azulejo · Español A1 — передача проєкту

Файл для продовження роботи в новому чаті. Встав його на початок розмови й скажи, що робити далі.

## Що це

Мобільна вебгра для вивчення іспанської з нуля. Один HTML-файл без збірки та залежностей:
vanilla JS, ручний рендер через `innerHTML`, делегування подій на контейнері `#app`.
Встановлюється як PWA на GitHub Pages.

- Репозиторій: `https://github.com/vladcherry/espanol-a1-juego`
- Адреса: `https://vladcherry.github.io/espanol-a1-juego/`
- Файли в корені репозиторію: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`

Реалізовано рівні 1–8 (усі `unlocked: true`).

## Готово

- Рівень 1, чотири розділи: `saludos` (8 слів), `colores` (10), `numeros` (10), `frases` (10)
- Режим «Повний рівень» — 16 випадкових питань упереміш, відкривається після всіх чотирьох розділів
- Кожен розділ: картки з транскрипцією та озвученням → квіз із випадковим типом питання
- Таймер забігу, найкращий час, точність, зірки (1–3), лічильник забігів, повторне проходження
- Мозаїка азулежу вгорі квіза: плитка на питання, заповнюється візерунком під час відповіді
- Озвучення через `speechSynthesis` (`es-ES`) з діагностикою збоїв і кнопкою перевірки на головному екрані
- Збереження прогресу: `window.storage` усередині артефакту Claude, `localStorage` поза ним
- Офлайн-робота через сервіс-воркер, встановлення як застосунку з іконкою
- Рівень 2 «У кафе», чотири розділи: `bebidas` (12 напоїв), `comida1` (11 страв), `comida2` (13 страв), `postres` (6 десертів) — версія кешу піднята до `azulejo-v2`
- На головному екрані прибрано кнопки «Перевірити звук» і «Скинути прогрес»
- Рівень 3 «Що я роблю», два розділи: `verbos1` (12), `verbos2` (12) — дієслова у першій особі (Yo…); версія кешу піднята до `azulejo-v3`
- Пройдені рівні (усі розділи здано) згортаються до заголовка з ⚡ (округлене середнє зірок), клік розгортає
- Емодзі-картинки до слів: мапа `EMOJI` (ключ — `es`) на старті додає `it.img` і вмикає режим `img` («вгадай за картинкою») там, де емодзі є для всіх слів розділу; кольори й цифри лишаються зі своїм візуалом. Версія кешу — `azulejo-v4`
- **Локальний словник**: слова більше не «джерело правди» в коді. `SEED` — вбудований дефолтний словник (наявні рівні 1–3); на старті `loadDict()` клонує його в `LEVELS` і зберігає під ключем `azulejo:dict:v1`. Далі все читається/пишеться зі сховища. Нові вбудовані рівні домержуються за `id`.
- **Мій словник** (`level.my`, `id:100`): окремий рівень для слів із фото; грабельний від 4 слів; екзамену немає.
- **Камера + Gemini**: кнопка «📷 Додати слова з фото» → `<input type="file" capture>` → base64 → `geminiExtract()` (модель `gemini-flash-lite-latest`, structured JSON: `es/uk/tip/emoji`) → екран `review` з чекбоксами → обране через `addToDict()` у «Мій словник». Ключ Gemini у `settings` (`azulejo:settings:v1`); якщо немає — екран `apikey` з інструкцією та посиланням на Google AI Studio. Версія кешу — `azulejo-v5`
- **Рівні фраз 4–8**: цілі фрази замість окремих слів, по два розділи (по 10 фраз) на рівень — `4` «Знайомство та small talk» (`presentaciones`, `charla`), `5` «У магазині» (`compras`, `pago`), `6` «У банку» (`banco1`, `banco2`), `7` «Міграційна служба» (`migra1`, `migra2`), `8` «Аптека та здоров’я» (`farmacia`, `salud`). Емодзі до фраз немає, тож режим `img` для них не вмикається. У `loadDict()` додано рядок, що завжди тримає «Мій словник» останнім після домержу нових вбудованих рівнів. Версія кешу — `azulejo-v6`
- **Кнопки «📷 Додати слова з фото» і «⚙ Gemini API-ключ»** перенесені з-під шапки вниз головного екрана (після списку рівнів, перед підвалом). Промпт `geminiExtract()` розширено: розпізнає не лише окремі слова, а й цілі фрази/речення (зберігає їх цілком, не розбиває; тримає знаки ¿? ¡!). Тексти екранів оновлені на «слова та фрази». Версія кешу — `azulejo-v7`
- **Виправлено сервіс-воркер**: на установці `addAll` брав файли з HTTP-кешу браузера (GitHub Pages віддає `max-age=600`), тож нова версія кешу наповнювалася файлами попереднього релізу. Тепер `new Request(u, { cache:'reload' })`. Версія кешу — `azulejo-v9`
- **Метод «Детектива»** (Reverse Learning) для рівнів фраз 4–8 — див. окремий розділ нижче. Версія кешу — `azulejo-v10`

## Структура коду в index.html

Порядок блоків згори вниз:

1. `<head>` — метатеги PWA, Google Fonts (Anton + Karla), увесь CSS у `<style>`
2. `LEVELS` — масив рівнів з усім контентом
3. Константи: `KEY`, `PER_Q_TARGET`, `EXAM_SIZE`

5. Сховище: `hasClaudeStorage`, `box.get/set`, `loadProgress`, `saveProgress`
6. Озвучення: `TTS`, `pickVoice`, `showNote`, `speechError`, `speak`
7. Утиліти: `shuffle`, `esc`, `level`, `fmt`, `stars`, `recSection`, `recExam`, `sectionsDone`
8. Генерація питань: `makeQuestion`, `startRun`
9. Рендер: `header`, `viewHome`, `viewLearn`, `viewQuiz`, `viewResult`, `render`
10. Забіг: `afterQuiz` (таймер), `answer`, `finish`
11. Один слухач `click` на `#app` з розбором `data-*`
12. Реєстрація сервіс-воркера

### Формат рівня

```js
{
  id: 2,
  tag: 'Nivel A1 · Lección 2',
  title: 'Сім’я та вік',
  note: 'Короткий опис під заголовком',
  unlocked: true,
  sections: [
    {
      id: 'familia',            // латиницею, унікальний у межах рівня
      title: 'Сім’я',           // українською, для інтерфейсу
      tag: 'Familia',           // іспанською, для надрядкового напису
      modes: ['es_ru','ru_es','audio_es'],
      items: [
        { es:'la madre', ru:'мама', tip:'ла ма́дре' }
      ]
    }
  ]
}
```

Поля `item`: `es`, `ru`, `tip` (транскрипція українською з наголосом) обов’язкові;
`color` (hex) потрібен для режиму `swatch`, `digit` (рядок) — для `digit` і `audio_digit`.

### Типи питань (`modes`)

| Режим | Питання | Варіанти |
|---|---|---|
| `es_ru` | іспанське слово | українські переклади |
| `ru_es` | український переклад | іспанські слова |
| `audio_es` | озвучення, кнопка 🔊 | іспанські слова |
| `swatch` | кольоровий квадрат | іспанські слова |
| `digit` | велика цифра | іспанські слова |
| `audio_digit` | озвучення | цифри |
| `img` | велике емодзі | іспанські слова |

Дистрактори — три випадкові елементи того самого розділу. Тому в межах розділу всі `ru` і всі `es`
мають бути унікальними, інакше з’явиться питання з двома правильними відповідями.

## Метод «Детектива» (Reverse Learning)

Альтернативний спосіб проходження рівнів фраз: спершу контекст, теорія — потім.
Кожен рівень 4–8 має одну «справу» — діалог із пронумерованими уликами.

Чотири фази (`state.caso = { phase, marked }`, екран `viewCaso()`):

1. **Огляд сцени** — місце, час, бріф і повний діалог. Улики підсвічені, але без перекладу.
2. **Збір улик** — той самий діалог, фрази клікабельні: тицяєш незрозуміле, воно позначається.
3. **Ключ шифру** — таблиця всіх улик із транскрипцією, перекладом і 🔊; твої позначки підсвічені.
   Внизу «нотатка детектива» — граматичне пояснення.
4. **Закриття справи** — експрес-квіз на `CASO_QUIZ` (8) питань з улик цієї справи.

### Формат справи

Справи живуть у **коді** (`const CASOS`), а не в словнику користувача: `attachCasos()`
чіпляє їх до `SEED` і до `LEVELS` після завантаження зі сховища, тож оновлення
доходять і до тих, у кого словник уже збережений.

```js
const CASOS = {
  4: {
    code:'Caso #01', title:'Expediente Contacto',
    place:'Коворкінг, Барселона · 19:00',
    brief:'Що сталося — одне речення для настрою',
    note:'Граматична нотатка, показується у фазі 3',
    lines: [ { w:'Persona A', t:'¡Hola! {1} Me llamo Vladimir.' } ],
    clues: [ { es:'Mucho gusto.', ru:'дуже приємно', tip:'му́чо ґу́сто' } ]
  }
};
```

`{n}` у тексті репліки — посилання на `clues[n-1]`. Нумерація з 1, **у порядку появи**
в діалозі. Текст улики зберігається лише в `clues`, у репліку він підставляється при рендері
(`casoLine()`), тож розсинхрону бути не може. У межах справи `es` і `ru` мають бути унікальні —
інакше в експрес-квізі з’явиться питання з двома правильними відповідями.

Прогрес справ — окреме сховище `progress.casos[levelId]` (не змішується з розділами
й екзаменом). Тип забігу розрізняє `state.runKind` — `'section' | 'exam' | 'caso'`.

## Як додати рівень

1. Дописати об’єкт у `LEVELS`, поставити `unlocked: true`.
2. Замінити відповідну заглушку (рівні 2 і 3 зараз порожні: `sections: []`).
3. Перевірити унікальність `ru` і `es` в межах кожного розділу.
4. Прогрес не зламається: ключі прив’язані до `id` рівня та `id` розділу.
5. Підняти версію кешу в `sw.js`: `azulejo-v1` → `azulejo-v2`, інакше встановлений застосунок
   продовжить показувати стару копію.
6. Залити `index.html` і `sw.js` у репозиторій.

## Зберігання прогресу

Ключ `azulejo:progress:v1`, значення — JSON:

```js
{
  v: 1,
  audio: true,
  sections: { '1:saludos': { best: 41200, stars: 3, bestAcc: 100, runs: 4 } },
  exams:    { '1':         { best: 92100, stars: 2, bestAcc: 94,  runs: 1 } },
  casos:    { '4':         { best: 17300, stars: 3, bestAcc: 100, runs: 1 } }
}
```

`best` — мілісекунди. `stars` і `bestAcc` накопичуються за максимумом, `best` — за мінімумом.
Усередині Claude і на GitHub Pages це різні сховища, прогрес між ними не переноситься.

## Оцінка забігу

- Точність = правильні відповіді / усього питань
- Швидко = загальний час ≤ `PER_Q_TARGET` (4200 мс) × кількість питань
- 3 зірки: 100 % і швидко; 2 зірки: точність ≥ 80 %; інакше 1 зірка

## Відомі обмеження

- **Озвучення залежить від системного голосу.** Якщо на пристрої немає іспанського голосу, `speak()`
  ловить помилку й показує підказку зі шляхом у налаштуваннях. Із коду це не лікується.
- **iOS вимагає жест.** `speechSynthesis.speak()` має викликатися в тій самій події, що й дотик.
  Не обгортати `speak()` у `setTimeout` і не викликати після `await` — це вже ламалося.
- **`cancel()` перед `speak()`** у Chrome інколи глушить фразу, тому викликається лише за
  `speaking || pending`.
- `confirm()` і `alert()` заблоковані в iframe артефакту — скидання прогресу зроблено подвійним натисканням.
- Google Fonts підтягуються з мережі; офлайн кешуються сервіс-воркером після першого запуску.
